# Source — immutable originals (org-wide)

Ingested org-wide material, copied UNTOUCHED. Never edit files here. This is the
audit trail that every synthesized claim in `../ingestion/` points back to.

- One file per source, dated. Include what it is and where it came from.
- Interview notes, meeting transcripts, docs, data exports, research.
- If it changes, add a new dated version — don't overwrite.

Only sources routed to the **org** brain land here. Domain sources go to
`domains/<domain>/second-brain/source/`. One source is never split across both.
