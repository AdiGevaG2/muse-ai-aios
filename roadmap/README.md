# Roadmap

Tracks change requests and priority shifts to the Unified Platform roadmap.
Not a source of product intent (`prd.md` in each feature folder is); this is
the log of what changed on the roadmap, when, and why.

## Files

- `changes.md` - log of roadmap/priority change requests: date, requester,
  what changed, reason, status.
- `current.md` - current prioritized view of the roadmap.
