# Corrections — deck

Local, skill-specific corrections. When you give this skill the SAME feedback
more than once, save it here as a short file so the fix sticks permanently.
The skill reads this folder on every run.

- One correction per file, named for the problem (e.g. `too-formal.md`).
- State the rule, not the story: "Put the metric before the recommendation."
- Distinct from the brains: corrections here are about HOW THIS SKILL WRITES,
  not domain knowledge. Domain facts go to the second-brain via /retro.
- Promote a correction that applies to many skills into the domain CLAUDE.md
  or brain instead of copying it around.
